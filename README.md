Day One现在是越来越臃肿了，不过我也并不需要那么多功能，甚至只使用Obsidian就能完成这部分内容

但是总觉的差点意思，所以VC一个Day Two玩具出来

## 主要功能

- MarkDown文件创建生成
- 按照创建日期、地点位置分类
- 支持导入MD文件和导出PDF和MD文件
- 支持附件插入

以上就是自己常用的一些功能，但是并没有继续使用DayOne的理由了，一键切换
